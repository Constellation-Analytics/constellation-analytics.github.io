# Personal Website

This repository contains the source code for my personal website.
constellation-analytics.github.io

Previously, my site was built using a website builder.  
This version is being developed entirely from scratch using HTML and CSS to give me full control over structure, performance, and design.

## 🎯 Purpose

- Showcase my projects
- Present my professional profile
- Experiment and improve my front-end development skills
- Maintain full ownership of my web presence

## 🛠 Tech Stack

- HTML5
- CSS3
- GitHub Pages (for hosting)

## 📂 Structure

The site is structured for clarity and scalability:

- `index.html` – Homepage
- `pages/` – Static pages (about, contact, etc.)
- `projects/` – Individual project pages
- `assets/` – Images and icons
- `style.css` – Global styling

## 🚀 Deployment

This site is deployed using GitHub Pages.

Any changes pushed to the main branch are automatically reflected live.
