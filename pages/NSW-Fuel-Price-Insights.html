About this dashboard

NSW Fuel Price, Insights and Trends

This dashboard visualises petrol and diesel prices across New South Wales, updated monthly from the NSW Government FuelCheck program. It covers all major fuel types including E10, U91, P95, P98, diesel, and LPG across more than a thousand stations statewide.

The data is loaded and transformed by a fully automated ELT pipeline built with Python, PostgreSQL, and GitHub Actions. Read about how the pipeline works in the pipeline project write-up.
